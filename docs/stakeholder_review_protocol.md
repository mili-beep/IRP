# Event and dashboard usability review protocol

Use this protocol only with consented independent reviewers or intended
facilities/security staff. Do not claim that this review has occurred until the
completed forms are saved and summarised.

For each reviewer, show one saved dashboard/event case without explaining the
priority first. Ask:

1. What system and time period does this event concern?
2. What priority does it have, and what evidence supports that priority?
3. What action would you take next?
4. Which field is unclear or missing?
5. Would this event be useful, distracting, or unsafe in a normal shift?

Record reviewer role, case ID, time to locate the event, response, and any
requested change. Report the number and type of reviewers, not their personal
identities. Treat this as qualitative usability feedback, not proof of safety
or deployment effectiveness.
