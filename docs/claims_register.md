# Claims Register

Research claims will be linked to a reproducible run, dataset checksum, configuration, and supporting metric.

Initial limitations to carry into every report:

- RBC-ASHRAE1312 real faults are controlled injections in one ERS facility, not naturally occurring maintenance events.
- A scenario filename is not proof of the precise fault onset time.
- Real and simulated schemas are different; simulation is out of scope for the first release.
- Results must not be described as general performance across buildings without external validation.
- The access-control example is synthetic architecture demonstration data, not a
  second Smart Facilities dataset or access-control anomaly evaluation.
- Event priority bands are transparent starting policy; no staff usability
  review or live operational validation has yet been completed.
