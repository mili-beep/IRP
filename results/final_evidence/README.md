# Final evidence pack

This is the compact, Git-friendly evidence package for report review. It is generated by `scripts/build_final_evidence.py` from the complete local `results/final_runs/` archive.

It includes frozen configurations, manifests, selected features, fold-level and summary metrics, model-comparison tables, QA reports, diagnosis evidence, and report-ready P01 figures. It excludes raw predictions, fold-membership tables, and model binaries because those make the complete archive about 4.1 GB.

## Important interpretation limits

- Results are controlled HVAC-fault experiments from one facility, not multi-building deployment validation.
- Fault sessions are labelled for the full recording day; zero delay is not a verified physical onset time.
- E16/E17 are instrumented-BMS diagnosis sensitivity studies, not symptom-only diagnosis.
- E18 reliability values are descriptive held-out evidence from this dataset, not probabilities guaranteed for a new building.
- The complete generated archive should be shared separately with assessors who need predictions, models, or full split membership.
